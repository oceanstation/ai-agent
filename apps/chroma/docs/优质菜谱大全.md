## 鸡蛋类

### 1. 番茄炒蛋 ⭐ | 约10分钟 | 2人份

**食材清单：**
| 食材 | 用量 | 说明 |
|------|------|------|
| 番茄 | 2个（约300g） | 选熟软多汁的 |
| 鸡蛋 | 3个（约150g） | 室温 |
| 小葱 | 1根 | 切葱花 |
| 大蒜 | 2瓣 | 切末（可选） |
| 食用油 | 3汤匙（45ml） | 要够多蛋才嫩 |
| 盐 | 3g（分两次用） | |
| 白糖 | 5g（1茶匙） | 不可省略 |
| 清水或牛奶 | 15ml | 打入蛋液，蛋更嫩 |

**步骤详解：**

**① 预处理食材（3分钟）**
- 番茄顶部划十字刀，开水烫15秒后撕皮。去皮口感顺滑，保留也可
- 去蒂切约2cm滚刀块。不要切太碎，否则变糊

**② 打蛋液（1分钟）**
- 蛋磕入碗，加1g盐 + 15ml水或牛奶
- 筷子顺一个方向充分搅打，至表面细腻泡沫、无块状蛋清

**③ 炒鸡蛋（2分钟）**
- 锅大火烧热，倒3汤匙油。油量要比平时多一倍！
- 油温六成热（微微冒烟），沿锅边倒入蛋液
- 底部凝固时用筷子从外向内轻划，让未凝蛋液流到锅底
- 炒至八成熟：边缘金黄、中间微湿 — **立即盛出，绝不恋战！**

**④ 炒番茄（3分钟）**
- 锅中留底油，放蒜末爆香10秒
- 倒番茄块，**中小火**炒约1分钟，边炒边用铲背轻压促出汁
- 加5g白糖，继续炒至番茄完全软烂、汤汁浓稠红亮（约2分钟）
- 判断标准：无大块番茄，汤色酱红

**⑤ 合炒出锅（20秒）**
- 倒入鸡蛋，加剩余2g盐
- **大火**快炒15-20秒让味道融合
- 撒葱花出锅

**💡 成功关键：** 盐一定最后放（早放番茄出水变汤）；糖不可省（中和酸味，不甜只是提鲜）；番茄要去皮；炒蛋油要宽

**⚠️ 失败分析：** 蛋老 → 火大或炒太久；一锅汤 → 盐放早了；寡淡 → 没放糖或番茄不熟

### 2. 青椒炒蛋 ⭐ | 约8分钟

**食材：** 青椒2个（200g）、鸡蛋3个、盐3g、食用油30ml、生抽少许（可选）

**步骤：**
1. 青椒去籽切菱形块；鸡蛋打散加1g盐
2. 热油1.5汤匙，六成热倒蛋液，底部凝固划散，八成熟盛出
3. 锅中补0.5汤匙油，倒青椒大火快炒40秒至颜色变深微软
4. 倒回鸡蛋，加剩余盐，大火翻炒20秒出锅

**💡 青椒保持脆感的关键是全程大火、不超过1分钟。**

### 3. 黄瓜炒鸡蛋 ⭐ | 约8分钟

**食材：** 黄瓜1根（200g）、鸡蛋3个、大蒜2瓣、盐3g、食用油30ml

**步骤：**
1. 黄瓜切约3mm菱形片；鸡蛋打散加1g盐；蒜切片
2. 热油1.5汤匙炒蛋至八成熟盛出
3. 锅中补0.5汤匙油，蒜片爆香，下黄瓜大火快炒30-40秒至微透明
4. 倒回鸡蛋，加盐，大火炒15秒出锅

**💡 黄瓜片不过薄（3mm最佳），全程不加水，保持爽脆。**

### 4. 韭菜炒鸡蛋 ⭐ | 约6分钟

**食材：** 韭菜1把（250g，选窄叶更香）、鸡蛋4个、盐4g、食用油30ml、白胡椒粉少许

**步骤：**
1. 韭菜择净，**充分沥干**（有水入锅会溅油出水），切3-4cm段
2. 蛋液加1g盐和白胡椒粉搅匀
3. 热油1.5汤匙，炒蛋八成熟盛出
4. 补0.5汤匙油，大火，倒韭菜快速翻炒20-30秒（变软即可）
5. 倒回鸡蛋加盐，大火快炒10秒立即出锅

**💡 韭菜30秒就够，炒久出水软烂失香。口诀：快下快翻快出锅。**

### 5. 木须肉 ⭐⭐ | 约20分钟

**食材：** 猪里脊150g、鸡蛋3个、干木耳15g、干黄花菜15g、黄瓜半根（100g）、胡萝卜50g、姜蒜适量

**腌肉料：** 料酒1茶匙 + 生抽1茶匙 + 淀粉1茶匙 + 少许油

**调味：** 生抽1汤匙、蚝油半汤匙、盐4g、水淀粉

**步骤：**
1. 木耳黄花菜温水泡发。木耳撕小朵，黄花菜去硬蒂。黄瓜胡萝卜切菱形片
2. 里脊逆纹切薄片（2mm），加腌料抓匀腌10分钟
3. 蛋液加1g盐，热油炒散八成熟盛出
4. 热油五成热下肉片，筷子拨散，变色盛出（约30秒）
5. 姜丝蒜片爆香，依次下胡萝卜（30秒）→木耳黄花菜（1分钟）→黄瓜（30秒）
6. 倒回肉片和鸡蛋，加生抽蚝油盐，大火翻炒，淋水淀粉勾薄芡

**💡 色彩搭配：黄（蛋）、黑（木耳）、橙（胡萝卜）、绿（黄瓜），每种分开处理保证各自熟度。**

### 6. 洋葱炒蛋 ⭐ | 约8分钟

**食材：** 洋葱1个（200g，紫皮更香）、鸡蛋3个、盐3g、食用油30ml、生抽少许

**步骤：**
1. 洋葱顺纹切5mm宽丝；蛋液加1g盐打散
2. 热油1.5汤匙炒蛋八成熟盛出
3. 补油0.5汤匙，倒洋葱丝中火炒1.5-2分钟至半透明微焦黄
4. 倒回鸡蛋加盐和少许生抽，大火炒15秒出锅

**💡 洋葱炒到半透明微焦才甜——生洋葱辛辣，炒透了自然甜。**

### 7. 鸡蛋羹 ⭐ | 约20分钟

**食材：** 鸡蛋2个（100g）、温水150-180ml（蛋液1.5倍，约40°C）、盐2g、生抽1茶匙、香油几滴、葱花少许

**步骤：**
1. 鸡蛋加盐充分打散，**缓缓倒入温水**边倒边搅
2. 用细筛网过滤到蒸碗（去除蛋筋和泡沫）
3. 撇去表面浮沫，盖上保鲜膜，牙签扎5-6个小孔
4. 蒸锅水烧开后放入蛋碗，**转中小火**蒸10分钟，关火焖2分钟
5. 取出淋生抽、香油，撒葱花

**💡 三大关键：温水（冷水硬开水成蛋花）、过筛去泡、中小火蒸。大火必出蜂窝！**

### 8. 虎皮鸡蛋 ⭐⭐ | 约30分钟

**食材：** 鸡蛋6-8个、生抽2汤匙、老抽半汤匙、白糖1汤匙、料酒1汤匙、姜蒜葱适量、清水200ml

**步骤：**
1. 鸡蛋冷水下锅，水开煮8分钟至全熟，泡冷水剥壳，表面划几刀（2mm深）
2. 锅中油烧至六成热（筷子入冒细泡），鸡蛋擦干水分小心放入，炸至表面起皱金黄（约2分钟）
3. 锅留底油爆香姜蒜葱，加生抽老抽白糖料酒200ml水烧开
4. 放入炸蛋，小火盖盖焖15分钟
5. 开盖大火收汁至浓稠裹蛋，撒葱花

**💡 蛋黄必须炸到起皱才能吸收汤汁入味。入锅前一定擦干水分防溅油。**

### 9. 苦瓜炒蛋 ⭐ | 约12分钟

**食材：** 苦瓜1根（250g）、鸡蛋3个、盐4g、白糖半茶匙、蒜2瓣、食用油30ml

**步骤：**
1. 苦瓜对半切，**刮净白瓤和白膜**（最苦就是它！），切3mm半月形薄片
2. 水开加1g盐几滴油，苦瓜焯40秒变翠绿捞出，过冷水沥干
3. 蛋液加1g盐打散，热油炒八成熟盛出
4. 蒜末爆香，倒苦瓜大火快炒1分钟
5. 倒回鸡蛋，加2g盐和白糖，翻匀出锅

**💡 去苦三步：刮净白膜 → 加盐焯水 → 放糖中和。做好后清甜微苦，绝非难以下咽。**

### 10. 荷包蛋烧豆腐 ⭐⭐ | 约20分钟

**食材：** 鸡蛋2个、嫩豆腐1块（350g）、葱姜蒜适量、生抽2汤匙、蚝油1汤匙、老抽半茶匙、白糖半茶匙、清水150ml、水淀粉

**步骤：**
1. 热油煎两个荷包蛋至两面金黄（各1分钟），取出切大块
2. 豆腐切2cm块，中火煎两面金黄盛出
3. 锅留底油爆香姜蒜葱段，加生抽蚝油老抽白糖150ml水烧开
4. 放入豆腐和荷包蛋块，中火煮5分钟入味
5. 大火淋水淀粉勾芡，汤汁浓稠出锅

**💡 荷包蛋吸收红烧汤汁后别有风味，既有蛋香又有酱香。**

## 豆腐类

### 11. 麻婆豆腐 ⭐⭐ | 约20分钟

**食材：**
| 食材 | 用量 | 说明 |
|------|------|------|
| 嫩豆腐 | 1块（400g） | 南豆腐或内酯豆腐 |
| 牛肉末 | 50g | 传统用牛肉 |
| 郫县豆瓣酱 | 30g（2汤匙） | 剁碎 |
| 豆豉 | 10g | 切碎 |
| 辣椒面 | 1茶匙（可选） | |
| 花椒粉 | 1茶匙 | 出锅撒 |
| 姜末、蒜末 | 各1汤匙 | |
| 青蒜苗 | 1根 | 切小段 |
| 生抽 | 1汤匙 | |
| 料酒 | 1汤匙 | |
| 白糖 | 半茶匙 | |
| 高汤/清水 | 200ml | |
| 食用油 | 2汤匙 | |
| 水淀粉 | 2茶匙淀粉+3汤匙水 | 分三次用 |

**步骤详解：**

**① 豆腐处理（2分钟）**
- 切2cm方块，盐水开焯1分钟捞出沥干（去豆腥、更紧实）

**② 炒酥牛肉末（2分钟）**
- 干锅不放油，下牛肉末中小火煸至干酥粒粒分明，盛出

**③ 炒底料（2分钟）**
- 锅倒2汤匙油，中小火下剁碎的豆瓣酱炒1分钟至油红
- 加豆豉碎、辣椒面、姜末蒜末炒30秒

**④ 煮豆腐（3分钟）**
- 倒200ml高汤或水，加生抽料酒白糖烧开
- 轻滑入豆腐块，中火煮3分钟（用勺背轻推，不用铲子）

**⑤ 三次勾芡（核心技法，约5分钟）**
- 第一次：淋入1/3水淀粉，轻推豆腐
- 第二次：1分钟后淋入1/3，轻推
- 第三次：再1分钟后淋入最后1/3，撒入牛肉末和青蒜段
- 三次芡让汤汁层层包裹，均匀入味

**⑥ 出锅**
- 将豆腐滑入盘中（不倾倒防碎），撒花椒粉

**💡 麻婆豆腐五字诀"麻辣烫酥嫩"：** 麻（花椒粉）、辣（豆瓣酱）、烫（勾芡保温）、酥（牛肉末干香）、嫩（豆腐入口即化）

### 12. 家常豆腐 ⭐⭐ | 约25分钟

**食材：** 老豆腐400g、五花肉末80g、青红椒各半个、木耳10g（泡发）、郫县豆瓣酱15g、葱姜蒜各适量、生抽1汤匙、蚝油1汤匙、白糖半茶匙、清水100ml、食用油30ml、水淀粉

**步骤：**
1. 老豆腐切1cm厚三角块，吸干水分，中火煎两面金黄盛出
2. 锅补油，下肉末煸至出油金黄
3. 加豆瓣酱小火炒出红油，加姜末蒜片炒香
4. 放入豆腐、木耳、青红椒块，加生抽蚝油白糖100ml水，大火烧开转中火焖3-5分钟
5. 水淀粉勾芡，撒葱段翻匀出锅

**💡 豆腐不碎秘诀：煎前吸干水分、下锅不急着翻、一面煎好再翻。**

### 13. 红烧豆腐 ⭐⭐ | 约20分钟

**食材：** 老豆腐1块（400g）、葱姜蒜适量、生抽2汤匙、老抽半汤匙、蚝油1汤匙、白糖1茶匙、清水150ml、食用油30ml、水淀粉

**步骤：**
1. 豆腐切2cm方块，吸干水分，中火煎四面金黄
2. 推豆腐到锅边，爆香葱段姜片蒜片
3. 加生抽老抽蚝油白糖150ml水，大火烧开转小火盖盖焖8-10分钟
4. 开盖大火淋水淀粉收浓汤汁，撒葱花

**💡 焖的时间不少于8分钟，豆腐才能入味。**

### 14. 鱼香豆腐 ⭐⭐ | 约20分钟

**食材：** 老豆腐350g、肉末80g、葱姜蒜末各1汤匙、泡红辣椒20g（剁碎）

**鱼香汁配比：** 白糖2汤匙（30g）+ 香醋1.5汤匙（22ml）+ 生抽1汤匙 + 料酒半汤匙 + 水淀粉（1茶匙淀粉+3汤匙水）+ 清水1汤匙

**步骤：**
1. 豆腐切块煎金黄
2. 炒肉末变色加泡辣椒碎炒出红油
3. 加葱姜蒜末大火爆香
4. 入豆腐，倒鱼香汁煮3分钟入味，大火收浓

**💡 鱼香无鱼——泡辣椒+葱姜蒜+糖醋=鱼香复合味。**

### 15. 客家酿豆腐 ⭐⭐⭐ | 约35分钟

**食材：** 老豆腐2块（600g）、猪肉馅200g（三分肥七分瘦）、干香菇5朵（泡发切碎）

**肉馅调味：** 生抽1汤匙、蚝油1茶匙、盐2g、白胡椒粉少许、淀粉1茶匙、香油几滴、葱姜水50ml（葱姜泡水15分钟）

**红烧汁：** 生抽1汤匙、蚝油1汤匙、老抽半茶匙、白糖半茶匙、清水200ml

**步骤：**
1. 肉馅加所有调味料和葱姜水，顺一个方向搅2-3分钟至上劲发黏
2. 豆腐切三角块（5×3×2cm），斜面用小勺挖0.5cm浅洞（勿挖穿）
3. 洞内抹干淀粉，填入肉馅抹平
4. 热油2汤匙，肉面朝下煎3分钟至金黄定型，再煎其余各面1分钟
5. 倒红烧汁烧开，轻入豆腐（肉面朝上），盖盖中小火焖12-15分钟
6. 开盖大火收汁，水淀粉勾薄芡，肉面朝上装盘，淋汁

**💡 肉馅搅上劲才能牢牢粘在豆腐上；先煎肉面定型是关键。**

### 16. 白菜炖豆腐 ⭐ | 约20分钟

**食材：** 大白菜半棵（400g）、老豆腐350g、粉丝30g（温水泡软）、葱姜适量、盐4g、白胡椒粉少许、食用油30ml、清水500ml

**步骤：**
1. 白菜叶撕大片，帮片薄。豆腐切块。粉丝泡软
2. 热油爆香葱姜，先炒白菜帮1分钟，再下叶炒软
3. 倒500ml水烧开，入豆腐中火炖8分钟
4. 入粉丝再炖3分钟至透明，加盐白胡椒粉出锅

### 24. 回锅肉 ⭐⭐⭐ | 约35分钟

### 25. 红烧肉 ⭐⭐⭐⭐ | 约2小时

**食材：** 三层五花肉600g（切3cm方块）、冰糖30g、生抽2汤匙、老抽1汤匙、料酒2汤匙（最好黄酒）、姜5片、葱2根（打结）、八角2颗、桂皮1小块、香叶2片、干辣椒2个（可选）、开水约800ml、盐3g（最后放）、食用油1茶匙

**步骤：**

**① 焯水（5分钟）**
- 五花肉冷水下锅加姜片料酒，煮开出沫，再煮2分钟
- 捞出用**温水**冲洗（不要冷水！热肉遇冷变硬）

**② 炒糖色（最关键，5分钟）**
- 锅放1茶匙油+30g冰糖，开**中小火**
- 不停搅动：冰糖融化→浅黄冒细泡→**琥珀色红棕冒大泡**→立刻下肉！
- 快速翻炒让每块肉均匀裹糖色
- ⚠️宁浅勿深，炒焦发苦整道菜毁掉

**③ 煸炒出油（3分钟）**
- 中火煸炒肉块至表面微黄、锅中明显出油
- 加姜葱八角桂皮香叶干辣椒炒香，加生抽老抽上色

**④ 炖煮（80-90分钟）**
- 倒滚烫开水没过肉约2cm
- 大火烧开撇沫，转**小火保持微滚**
- 盖盖炖1-1.5小时，中间翻动1-2次

**⑤ 收汁（5-10分钟）**
- 筷子能轻松穿透肉皮→炖好了
- **此时才加盐**（早放盐肉不易烂）
- 挑出香料，大火收汁，不停翻动防粘锅
- 收至浓稠红亮裹肉即可

**💡 五大成功标准：** 色红亮、肥不腻入口化、瘦酥不柴、咸甜适口、汁浓挂肉。

### 36. 宫保鸡丁 ⭐⭐⭐ | 约25分钟

**食材：**
| 食材 | 用量 | 说明 |
|------|------|------|
| 鸡腿肉 | 300g（2个大鸡腿） | 去骨，比鸡胸嫩 |
| 生花生米 | 50g | |
| 黄瓜 | 半根 | 切丁 |
| 胡萝卜 | 小半根 | 切丁 |
| 大葱白 | 1段 | 切小段（葱弹子） |
| 干红辣椒 | 6-8个 | 剪段去籽 |
| 花椒 | 1茶匙 | |
| 姜片、蒜片 | 各适量 | |

**腌鸡丁：** 生抽1茶匙 + 料酒1茶匙 + 盐1g + 淀粉1茶匙 + 蛋清半个

**宫保汁：** 白糖1.5汤匙（22g）+ 香醋1汤匙（15ml）+ 生抽1.5汤匙 + 料酒半汤匙 + 水淀粉（1.5茶匙淀粉+3汤匙水）+ 老抽几滴 + 盐少许

**步骤：**

**① 炸花生米（6分钟）**
- 花生米冷水冲后沥干。冷锅冷油，**小火**慢炸5-6分钟
- 不停翻动，炸至颜色变深"噼啪"响。捞出摊开晾凉（凉了才脆！）

**② 准备鸡丁（10分钟）**
- 鸡腿去骨，带皮切1.5cm方丁
- 加腌料抓匀腌15分钟

**③ 滑鸡丁（1分钟）**
- 热油2汤匙，四成热（约120°C）下鸡丁
- 筷子快速拨散，变白立刻盛出（约40秒）

**④ 炒糊辣味（1分钟）**
- 锅留底油转小火。先下花椒炸香（20秒），变色后捞出花椒粒
- 放入干辣椒段、姜蒜葱段，小火炒至辣椒暗红、香味冲鼻（约30秒）
- 这就是宫保菜的标志——**"糊辣味"**

**⑤ 烹汁出锅（1分钟）**
- 转大火，倒入鸡丁、黄瓜丁、胡萝卜丁快速翻几下
- 沿锅边淋宫保汁，大火烧至冒泡浓稠，边翻边收汁（约20秒）
- **最后**倒入花生米，大火翻炒5秒出锅

**💡 糊辣荔枝味：** 糊=辣椒炒暗红的烟熏感；辣=花椒辣椒的麻辣；荔枝=糖醋酸甜回味。花生米必须最后放保持酥脆！

2. 锅不放油或少油，牛肉丝中小火慢煸（约6-8分钟），经历出水→蒸发→出油→干香。煸至深色干香盛出
3. 补少许油小火炒花椒干辣椒至暗红色
4. 加姜蒜芹菜大火炒1分钟
5. 倒牛肉丝加生抽糖盐大火炒20秒

**💡 干煸≠普通炒菜——不加水中小火慢慢把肉的水分炒干，口感是干香嚼劲不是嫩滑。**

### 53. 孜然牛肉 ⭐⭐ | 约15分钟

**食材：** 牛肉250g（切片）、洋葱半个、孜然粉1.5茶匙、辣椒粉半茶匙、白芝麻少许、生抽1汤匙、料酒1汤匙、盐2g、油2汤匙

2. 热油滑散牛肉变色盛出
3. 余油炒洋葱软
4. 倒牛肉，撒孜然粉辣椒粉生抽盐，大火快炒15秒，撒芝麻出锅

**💡 孜然粉最后撒，高温激发香气。早撒的孜然香散大半。**

## 鱼虾类

### 54. 清蒸鲈鱼 ⭐⭐⭐ | 约25分钟

**食材：** 活鲈鱼1条（500-600g）、大葱2根（1根切段1根切细丝）、姜1大块（部分切片部分切丝）、红椒少许（切丝配色）、蒸鱼豉油3汤匙、料酒2汤匙、盐少许、食用油3汤匙（泼油用）

**步骤：**

**① 处理鱼（5分钟）**
- 去鳞去鳃去内脏，**刮净腹内黑膜**（腥味元凶）
- 两面各划三刀（深至鱼骨，入味均匀），擦干鱼身水分
- 抹少许盐料酒腌10分钟。鱼肚塞姜片葱段

**② 蒸鱼（核心：火候！10分钟）**
- 蒸锅水先烧到大开。蒸盘底铺葱段（让鱼离盘底透气）
- 鱼放葱段上，水开入锅。**大火蒸8分钟**（500g公式：8分钟+每增100g多1分钟）
- 关火不要开盖，焖2分钟

**③ 去腥淋油（3分钟）**
- 取出鱼盘，**倒掉盘中蒸出的汁水**（腥味重，必须倒！）
- 去掉鱼身上姜葱
- 鱼身铺满葱丝姜丝红椒丝。沿四周淋蒸鱼豉油
- 另锅烧3汤匙油至冒烟（约200°C），均匀泼在葱姜丝上——"滋啦"一声！

**💡 蒸鱼四大关键：鱼新鲜 + 水开才蒸 + 大火蒸焖结合 + 蒸汁必须倒掉。**

### 55. 红烧鱼 ⭐⭐⭐ | 约35分钟

**食材：** 鲤鱼/草鱼1条（600-750g）、葱姜蒜适量、生抽2汤匙、老抽1汤匙、料酒2汤匙、香醋1汤匙、白糖1茶匙、八角1颗、干辣椒2个、盐3g、淀粉少许（裹鱼）

**步骤：**
1. 鱼处理净划斜刀，**彻底擦干**水分，薄薄扑一层干淀粉
2. 热锅多油烧至冒烟，轻放鱼。不要动！中大火煎3分钟至金黄，晃动锅鱼能滑动再翻面，再煎3分钟
3. 鱼盛出，锅留底油爆香葱姜蒜八角干辣椒
4. 加生抽老抽料酒香醋白糖，倒开水300ml烧开
5. 放回鱼，用勺反复舀汁浇鱼身（不翻鱼更完整）。中小火炖10-12分钟
6. 大火收汁2-3分钟，鱼滑入盘中，浇汁

**💡 煎鱼不破口诀：擦干→热锅→多油→不动→再翻。**

### 56. 糖醋鱼 ⭐⭐⭐ | 约30分钟

**食材：** 草鱼1条（600g）、盐2g、料酒2汤匙、姜葱腌鱼用、玉米淀粉约100g（裹鱼）

**糖醋汁：** 白糖4汤匙 + 白醋3汤匙 + 番茄酱3汤匙 + 生抽1汤匙 + 水5汤匙 + 水淀粉少许

**步骤：**
1. 鱼处理净。从最厚处垂直切到骨（隔2cm一刀），再45度斜片入让鱼肉外翻（牡丹花刀）
2. 抹盐料酒姜葱腌10分钟。每个刀口塞入淀粉
3. 七成热油，拎鱼尾先浇热油定型刀口，再整条入锅。中火炸8分钟至金酥。小心捞出
4. 另锅倒糖醋汁中火熬至浓稠冒大泡
5. 浇汁在鱼身上，撒葱丝

**💡 牡丹花刀：先垂直切到骨→45度斜片入→鱼肉外翻如牡丹花瓣。**

### 57. 红烧带鱼 ⭐⭐⭐ | 约35分钟

**食材：** 带鱼500g、葱姜蒜、生抽2汤匙、老抽1汤匙、料酒3汤匙（腥！多放酒）、香醋1汤匙、白糖1茶匙、八角1颗、干辣椒2个、淀粉适量

**步骤：**
1. 带鱼去头鳍内脏。**刮掉银白色表层**（腥味来源！）。切5-6cm段，吸干，抹盐料酒腌10分钟
2. 裹薄淀粉，热油中火煎两面金黄盛出
3. 锅留底油爆香葱姜蒜八角辣椒，放带鱼段
4. 加生抽老抽料酒香醋白糖，倒开水200ml烧开
5. 中小火盖盖炖10分钟，开盖大火收汁3分钟（少翻动防碎）
6. 小心夹出摆盘，淋汁

**💡 去腥三招：刮银膜 + 多料酒 + 放醋。**

### 58. 水煮鱼 ⭐⭐⭐⭐ | 约35分钟

**食材：** 草鱼/黑鱼1条（约1.5kg取片）、黄豆芽200g、莴笋半根、干辣椒20g（剪段）、花椒2汤匙、郫县豆瓣酱2汤匙、火锅底料少许、姜蒜末各适量

**鱼片上浆：** 盐3g + 料酒2汤匙 + 白胡椒粉少许（抓1分钟起胶）→ 加清水2汤匙（抓吸收）→ 加蛋清1个+淀粉2汤匙（抓匀）→ 封油少许

**步骤：**
1. 鱼肉斜刀45度切3-4mm蝴蝶片（第一刀皮不切断，第二刀切断）。鱼骨剁块
2. 鱼片按上浆步骤腌15分钟以上
3. 豆芽莴笋焯水1分钟，铺大碗底
4. 热油3汤匙，豆瓣酱小火炒2分钟出红油，加姜蒜末。倒清水或高汤800ml，放鱼骨煮10分钟出味
5. 捞出鱼骨放豆芽上。汤保持**微沸**，一片片下鱼片，不搅！1分钟变白连汤倒入碗
6. 撒蒜末。锅里烧100ml油冒烟，撒上干辣椒花椒立刻关火，浇鱼片上"滋啦"一声

**💡 鱼片秘诀：上浆出胶、水面微沸不滚、1分钟就关火、不翻动。**

### 59. 酸菜鱼 ⭐⭐⭐⭐ | 约30分钟

**食材：** 草鱼1条（1.2kg取片）、四川老坛酸菜200g、泡椒5-6个、干辣椒5-6个、花椒1茶匙、姜5片、蒜5瓣、野山椒水2汤匙（灵魂）、白胡椒粉少许、白醋1汤匙、盐3g

**步骤：**
1. 酸菜切丝泡水5分钟挤干。干锅不下油，中小火炒干酸菜水分（约2分钟）——更香更脆！

3. 热油爆香姜蒜泡椒，下酸菜炒2分钟，下鱼骨炒变色
4. 倒800ml水加野山椒水白胡椒粉，大火煮10分钟出味
5. 捞出酸菜鱼骨铺碗底。汤微沸放鱼片，1分钟变白加白醋
6. 连汤倒入碗，放干辣椒花椒。另锅烧热油淋上

**💡 酸菜先干炒去水——很多酸菜鱼馆的不传之秘。**

### 60. 番茄鱼 ⭐⭐⭐ | 约25分钟

### 84. 番茄蛋汤 ⭐ | 约10分钟

**食材：** 番茄1个（约150g）、鸡蛋2个、葱花、盐3g、白胡椒粉少许、油1汤匙

**💡 番茄先炒成酱再加水，汤色红亮味浓。蛋液慢慢倒不搅动，才能形成漂亮的丝状蛋片。**

## 西餐经典

### 106. 完美牛排（2人份）⭐⭐⭐ | 约20分钟

**食材：**
| 食材 | 用量 | 说明 |
|------|------|------|
| 西冷/肉眼牛排 | 2块（每块200g） | 提前30分钟从冰箱取出回温至室温 |
| 粗海盐 | 1茶匙 | |
| 现磨黑胡椒 | 半茶匙 | |
| 大蒜 | 2瓣（拍碎带皮） | |
| 橄榄油 | 2汤匙 | |
| 无盐黄油 | 30g | |
| 新鲜迷迭香/百里香 | 1枝 | |

**步骤详解：**

**① 牛排预处理（回温+调味，30分钟）**
- 将牛排从冰箱取出，放入盘中室温回温30分钟。**冰牛排直接下锅=外焦里生！**
- 用厨房纸**彻底拍干**牛排表面水分（有水分煎不出焦壳）
- 两面均匀撒粗海盐和现磨黑胡椒，轻轻按压让调料附着
- 静置10分钟等盐渗透

**② 煎牛排（6-7分钟）**
- 平底锅（铸铁锅最佳）大火烧至**冒烟**（约200-220°C）
- 倒入橄榄油润锅，用夹子放入牛排
- **第一面不要移动！**煎3-4分钟至金黄焦壳形成
- 判断可否翻面：肉能自由滑动
- 翻面再煎2-3分钟
- 加入黄油、拍碎的大蒜、迷迭香
- 转中小火，用勺子不断舀起黄油汁浇在牛排上（这叫"浇油法"，约1分钟）

**③ 休息（5分钟，极其重要！）**
- 夹出牛排，放在烤架或砧板上
- 盖锡纸，**静置休息5分钟**（让肉汁在内部重新分布）
- 不休息直接切的牛排=满盘肉汁流出=又干又柴！

**④ 切片上桌**
- 逆着肉的纹理斜切成约1cm厚片
- 淋上锅中剩余的黄油香草汁

**💡 熟度参考（按手指按压手感判断）：**
- 三分熟（Rare）：内部温度约52°C，手指按虎口偏软
- 五分熟（Medium Rare）：内部温度约57°C，触感有弹性
- 七分熟（Medium）：内部温度约63°C，触感较紧实
- 全熟（Well Done）：内部温度约71°C，触感硬

**⚠️ 绝对不能做的三件事：**
- 冰冻牛排直接下锅
- 牛排表面有水就下锅
- 煎完不休息直接切

### 107. 经典番茄意面（2人份）⭐⭐ | 约30分钟

**食材：**
| 食材 | 用量 | 说明 |
|------|------|------|
| 意面（Spaghetti） | 200g | |
| 橄榄油 | 2汤匙 | |
| 大蒜 | 3瓣（切碎） | |
| 洋葱 | 半个（切丁） | |
| 罐装去皮番茄 | 400g | 比新鲜番茄味更浓 |
| 干牛至（Oregano） | 1茶匙 | |
| 盐和黑胡椒 | 适量 | |
| 新鲜罗勒叶 | 1把 | 没有可用干罗勒 |
| 帕玛森奶酪 | 适量磨碎 | |

**步骤：**

**① 煮意面（8-10分钟）**
- 大锅水（至少3L），水开后加**满满一把盐**（约10g——煮面水要像海水一样咸！）
- 放入意面，按照包装时间煮到「al dente」（弹牙口感）。尝一下——外软心微硬就是最佳状态
- 保留1杯（约200ml）煮面水（含淀粉，后面调整酱汁稠度用）

**② 做番茄酱汁（15分钟）**
- 平底锅中火热橄榄油，下洋葱丁炒3-4分钟至透明
- 下蒜末炒30秒至出香
- 倒入罐装番茄（用铲子压碎整颗番茄），加干牛至、盐、黑胡椒
- 中火煮10-12分钟，期间不时搅拌，直到酱汁明显浓缩
- 关火前撕入一半新鲜罗勒叶

**③ 混合装盘（2分钟）**
- 将煮好的意面倒入酱锅
- 中大火翻炒1-2分钟，让每根面均匀挂酱
- 如果太干就加入留存的煮面水（淀粉水能让酱汁更好附着面条）
- 盛盘，撒大量帕玛森奶酪碎和剩余罗勒叶

**💡 两个关键：煮面水要像海水咸；保留的煮面水是用来调整酱汁的"神器"——里面的淀粉能让酱汁丝滑地挂在面上。**

## 烘焙甜点

### 109. 戚风蛋糕（8英寸）⭐⭐⭐ | 约90分钟

**食材清单：**

**蛋黄糊：**
| 食材 | 用量 | 说明 |
|------|------|------|
| 蛋黄 | 4个（约60g） | 蛋白蛋黄分离要彻底，蛋黄破一点就不能用 |
| 细砂糖 | 20g | |
| 植物油 | 40ml | 玉米油或色拉油，不要花生油橄榄油 |
| 牛奶 | 40ml | 室温 |
| 低筋面粉 | 60g | 必须过筛 |
| 玉米淀粉 | 10g（可选） | 让蛋糕更细腻 |

**蛋白霜：**
| 食材 | 用量 | 说明 |
|------|------|------|
| 蛋白 | 4个（约120g） | 打蛋盆和打蛋头必须无油无水！ |
| 细砂糖 | 40g | 分三次加入 |
| 柠檬汁/白醋 | 几滴 | 稳定蛋白霜 |

**步骤详解：**

**① 制作蛋黄糊（10分钟）**
1. 蛋清蛋黄彻底分离（蛋黄不能有一丝混入蛋白中）
2. 蛋黄加20g糖，手持打蛋器搅至颜色变浅、体积膨胀、浓稠
3. 分次加入植物油搅匀，再分次加入牛奶搅匀
4. 低粉过筛后加入（必须过筛防结块），Z字形翻拌至无干粉。**不要画圈搅！**会起面筋蛋糕不松软

**② 打发蛋白霜（最关键！15分钟）**
1. 蛋白中加入几滴柠檬汁
2. 电动打蛋器中速打发，出现大泡沫时加入1/3糖
3. 泡沫变细腻时加第二次1/3糖
4. 出现纹路时加最后1/3糖
5. 持续打发至**硬性发泡**——提起打蛋头蛋白霜呈直立小尖角，倒扣盆蛋白不流动
6. 📌 判断到位：①坚硬直立尖角 ②盆倒扣不动 ③蛋白霜有光泽感

**③ 混合（5分钟）**
1. 取1/3蛋白霜入蛋黄糊，翻拌均匀（从底部翻起，动作轻快）
2. 倒回剩余蛋白霜中，同样手法翻拌均匀。**不要消泡！**
3. 混合好的是淡黄色蓬松面糊，倒入8寸活底模具
4. 模具**不要抹油**！抹油蛋糕爬不高！
5. 轻震几下消除大气泡

**④ 烘烤（50分钟）**
1. 烤箱提前预热到160°C
2. 模具放中层，上下火160°C烤45-50分钟
3. 前30分钟**绝对不能开烤箱门**！冷空气会让蛋糕瞬间塌陷
4. 判断是否烤好：牙签插入无湿面糊带出；轻按蛋糕表面回弹

**⑤ 倒扣冷却（1小时+）**
1. 出炉立即把模具**倒扣**在冷却架上（或两个碗之间悬空）
2. 等**完全冷却**（至少1小时）才能脱模
3. 用脱模刀沿模具壁划一圈，取出蛋糕

**💡 失败及原因：**
- 塌腰 → 没烤透或没凉透就脱模
- 回缩/凹陷 → 蛋白打发不够或开门太早或没及时倒扣
- 底部凹陷 → 底火太高
- 内部湿黏 → 烤的时间不够
- 爬不高 → 模具抹油了或蛋白消泡了

### 110. 黄油曲奇（约20块）⭐⭐ | 约40分钟

**食材：**
| 食材 | 用量 | 说明 |
|------|------|------|
| 无盐黄油 | 100g | **室温软化**（手指轻按有凹痕），不是融化！ |
| 细砂糖/糖粉 | 50g | 糖粉口感更酥 |
| 鸡蛋 | 1个（约50g，打散） | 室温 |
| 低筋面粉 | 150g | |
| 香草精 | 几滴（可选） | |
| 盐 | 一小撮 | |

**步骤：**
1. 软化黄油（手指轻压出痕即可，不是液体！）加糖，打蛋器打至颜色发白体积膨胀（约2分钟）
2. 分2-3次加入蛋液，每次打匀再加下一次
3. 加香草精打匀
4. 低粉过筛加入，刮刀翻拌成面团。无干粉即可，**不要揉搓过度**（面团起筋曲奇就不酥了）
5. 面团分约15g小球，排烤盘上（间隔5cm以上，烤时摊开）
6. 用手掌压扁，叉子压出花纹
7. 烤箱预热180°C，中层烤10-12分钟至边缘金黄
8. 出炉烤盘上冷却5分钟再转移到冷却架

**💡 黄油务必软化而非融化——液态黄油做不出酥脆曲奇。**

### 111. 基础白面包（450g吐司）⭐⭐⭐ | 约2小时（含发酵）

**食材：**
| 食材 | 用量 | 说明 |
|------|------|------|
| 高筋面粉 | 250g | 必须高筋，不能用低筋 |
| 细砂糖 | 20g | |
| 盐 | 3g | 盐和酵母不能直接接触！ |
| 即发酵母 | 3g | |
| 鸡蛋 | 1个 | |
| 牛奶 | 130ml（室温） | |
| 无盐黄油 | 20g | 室温软化 |

**步骤：**

**① 揉面（15分钟）**
1. 面粉+糖+酵母混合（盐远离酵母放旁边），加鸡蛋和牛奶揉成团
2. 面团摊开包入软化黄油，继续揉
3. **手揉约10-15分钟**（或厨师机8分钟），揉到——取一小块面团拉开能成**薄膜**（"手套膜"）。这是面包松软的关键！
4. 检测：面团光滑不粘手，拉开薄膜不易破、破了是光滑圆孔

**② 一发（约1小时）**
1. 面团整圆放入抹油碗中，盖湿布或保鲜膜
2. 放在温暖处（28°C左右，比如烤箱中放一碗热水）
3. 发酵至2倍大（约1小时）。判断：手指蘸面粉戳洞，洞口不回缩不塌陷

**③ 排气整形**
1. 取出面团轻轻按扁排气（不要揉！会断筋）
2. 擀成长方形卷起，收口朝下放入吐司模

**④ 二发（约45分钟）**
1. 盖湿布再次发酵
2. 发到模具8-9分满

**⑤ 烘烤（30-35分钟）**
1. 烤箱预热180°C
2. 中层烤30-35分钟
3. 烤15分钟后看上色够了就盖锡纸防焦
4. 出炉立即脱模，放冷却架完全冷却再切片

**💡 手套膜是面包好不好吃的关键分水岭。手揉要有耐心，像搓衣服一样推出去拉回来。**

## 广式老火靓汤

> 广式老火靓汤讲究"煲三炖四"——冷水下料、大火煮沸转小火慢煲2-3小时、出锅前才放盐。中途不加水。

### 112. 胡萝卜玉米猪骨汤 ⭐⭐ | 约2小时

**食材：** 猪筒骨/扇骨500g、甜玉米2根（切段）、胡萝卜2根（滚刀块）、马蹄5-6个（去皮）、蜜枣2颗、生姜3片、盐适量

**步骤：**
1. 猪骨冷水下锅大火焯水5分钟，撇净浮沫，取出温水冲干净血渣
2. 玉米切段，胡萝卜去皮切滚刀块，马蹄去皮洗净
3. 所有材料（除盐外）入汤煲，加足量冷水（要一次性加够，中途加水汤会变淡）

### 常用调味汁配方

| 酱汁名称 | 精确配方 | 适用菜品 |
|----------|----------|----------|
| **鱼香汁** | 糖3勺 + 醋2勺 + 生抽1勺 + 料酒1勺 + 淀粉水2勺 | 鱼香肉丝、鱼香茄子 |
| **宫保汁** | 糖1.5勺 + 醋1勺 + 生抽1.5勺 + 料酒半勺 + 淀粉水3勺 | 宫保鸡丁 |
| **糖醋汁** | 糖3勺 + 醋2.5勺 + 生抽1勺 + 番茄酱1勺 + 水3勺 | 糖醋排骨、糖醋里脊 |
| **红烧汁** | 生抽2勺 + 老抽1勺 + 糖1勺 + 料酒1勺 + 水适量 | 红烧肉、红烧鱼 |
| **照烧汁** | 生抽2勺 + 味淋2勺 + 糖1勺 + 蜂蜜1茶匙 | 照烧鸡腿 |

### 肉类腌制通用公式

| 肉类 | 配方 | 要点 |
|------|------|------|
| **猪肉** | 料酒1勺 + 生抽1勺 + 盐少许 + 淀粉1勺 + 水1勺 + 油封 | 抓至水完全吸收 |
| **鸡肉** | 料酒1勺 + 生抽1勺 + 盐少许 + 淀粉1勺 + 蛋清半个 | 蛋清让肉片更滑 |
| **牛肉** | 料酒1勺 + 生抽1勺 + **小苏打1/4茶匙** + 淀粉1勺 + 水2勺 + 油封 | 小苏打是软化关键 |
| **鱼肉** | 盐+料酒+白胡椒粉（先抓出胶）+ 蛋清+淀粉+油封 | 先抓出胶再上浆 |

### 核心烹饪技巧速查

1. **火候掌握**：青菜肉丝→大火快炒；根茎类→中火；炖肉→小火慢炖
2. **焯水原则**：肉类冷水下锅撇沫；蔬菜水开下锅（加盐油保绿）
3. **勾芡比例**：淀粉:水 ≈ 1:3，最后一步淋入
4. **油温判断**：三四成（微热）→五六成（筷子冒细泡）→七八成（大量冒泡微烟）→冒青烟（九成）
5. **盐量控制**：一道菜约3-5g盐；有酱油豆瓣酱要相应减量；炖肉类最后放盐
6. **煲汤要诀**：冷水下料、一次加足水、大火煮沸转小火、出锅前放盐、中途不添水

### 炒饭三大铁律

- 必须隔夜冷饭（水分少才能粒粒分明）
- 大火热锅快炒
- 酱油炒饭用猪油提香

### 烘焙四大关键

- 戚风蛋糕模具不抹油（抹油爬不高）
- 出炉立即倒扣（防回缩塌陷）
- 黄油室温软化（非融化）
- 揉面要到扩展阶段（手套膜）

### 蒸鱼时间公式

| 鱼重 | 蒸制时间 |
|------|----------|
| 400-500g | 大火8分钟 + 焖2分钟 |
| 500-600g | 大火9分钟 + 焖2分钟 |
| 600-750g | 大火10分钟 + 焖2分钟 |

每增100g多蒸1分钟
